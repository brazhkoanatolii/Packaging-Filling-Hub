# Packaging-Filling-Hub

PWA для электронных журналов фасовочного участка. Google Sheets остаётся главным источником данных; приложение даёт удобные формы, локальную работу без сети, очередь синхронизации и контроль конфликтов.

## Уже работает

- две рабочие роли: начальник участка и старший механик;
- начало смены через полный состав бригады с отметкой присутствующих;
- постоянное напоминание для первой смены: заполнить табель и проверить 13 весов, без блокировки остальных разделов;
- полный график 2/2 для смен A и B, месячный табель фактических часов и причин отсутствия;
- перенесённые из прежней программы персонал, должности, составы смен и настройки рабочего времени;
- быстрый обход весов F1–F13 с переходом по Enter;
- вторая смена без обязательного повторного контроля весов;
- постоянные дата и время `Europe/Vilnius`, светлая и тёмная темы;
- переключатель основной навигации и даты RU / EN / LT;
- меню будущих рабочих разделов, включая упаковку, ремонт, несоответствия, продукцию, склад и документы;
- полноценный раздел персонала с фильтрами, редактированием и архивированием без удаления;
- график отпусков доступен начальнику для заполнения и старшему механику для просмотра; центр настроек персонала, смен и табеля доступен только начальнику;
- обязательный выбор исполнителя перед каждой записью;
- добавление, исправление и аннулирование с причиной;
- локальная очередь операций и автоматическая отправка при появлении сети;
- проверка версий без тихой перезаписи чужих изменений;
- обновление источника каждые 60 секунд и вручную;
- адаптивный интерфейс для компьютера и телефона;
- установка как PWA и офлайн-запуск.

> Прототип запускается в безопасном демонстрационном режиме. Запись в рабочую Google-таблицу отключена до настройки корпоративного OAuth и контролируемого теста.

Защищённый шлюз Google, поставщик данных и дополнение Apps Script уже подготовлены. Секреты Google хранятся только в локальном `.env` на рабочем компьютере и не попадают в браузер или GitHub.

## Установка на Windows

Готовый ZIP-пакет собирается без секретов Google:

```powershell
npm run build:windows
```

В папке `dist` появятся архив версии и файл контрольной суммы SHA256. На компьютере начальника запускается `INSTALL-MANAGER.cmd`, на компьютере старшего механика — `INSTALL-SENIOR-MECHANIC.cmd`, дома — `INSTALL-HOME-MANAGER.cmd`. Установщик создаёт локальную копию, ярлык и автозапуск, но сохраняет существующий `.env` при обновлениях.

Пошаговая инструкция: [README-INSTALLATION-RU.md](README-INSTALLATION-RU.md). Работа из дома: [HOME-WORK-RU.md](HOME-WORK-RU.md). Точный статус готовности: [docs/DEPLOYMENT-READINESS-RU.md](docs/DEPLOYMENT-READINESS-RU.md).

## Запуск для разработки

Требуется Node.js 20 или новее.

```powershell
npm start
```

Откройте `http://127.0.0.1:4173`.

После настройки Google используется команда:

```powershell
npm run start:gateway
```

## Проверка

```powershell
npm run check
```

## Архитектура

Раздел «Очистка циклонов» поддерживает ввод, отдельную офлайн-очередь, чтение Google и статистику внутри программы. Для реального подключения требуется развернуть API и согласовать OAuth: [инструкция](docs/CYCLONE-GOOGLE-SETUP-RU.md).

Интерфейс обращается к сервисам, сервисы — к репозиториям, а репозитории — к поставщикам данных. UI не читает Google Sheets или IndexedDB напрямую. Это позволяет подключать новые журналы и заменить демонстрационный источник на защищённый корпоративный API без копирования бизнес-логики.

Подробности: [docs/architecture.md](docs/architecture.md), [docs/google-integration.md](docs/google-integration.md) и [пошаговая инструкция](docs/GOOGLE-SETUP-RU.md).
