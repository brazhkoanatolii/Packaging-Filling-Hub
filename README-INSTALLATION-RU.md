# Установка Packaging-Filling-Hub на Windows

## Что подготовлено

Установочный комплект ставит программу в `%LOCALAPPDATA%\Packaging-Filling-Hub`, создаёт ярлык на рабочем столе, запускает локальный защищённый шлюз и добавляет его в автозапуск текущего пользователя Windows. Для работы не нужны права администратора.

Каждый компьютер получает только одну рабочую роль:

- компьютер начальника участка — `INSTALL-MANAGER.cmd`;
- компьютер старшего механика — `INSTALL-SENIOR-MECHANIC.cmd`;
- домашний компьютер начальника — `INSTALL-HOME-MANAGER.cmd`.

Программа работает через `http://127.0.0.1:4174`. Это позволяет установить PWA в Edge/Chrome и продолжать работу с локальным кэшем без доступа к интернету или другому компьютеру.

## Перед установкой

1. Установите Node.js 20 LTS или новее с официального сайта Node.js.
2. Распакуйте ZIP полностью в отдельную папку. Не запускайте установку внутри ZIP.
3. Закройте ранее открытую версию программы, если она есть.

## Установка

На компьютере начальника дважды нажмите `INSTALL-MANAGER.cmd`.

На компьютере старшего механика дважды нажмите `INSTALL-SENIOR-MECHANIC.cmd`.

На домашнем компьютере начальника дважды нажмите `INSTALL-HOME-MANAGER.cmd`. Подробности и правила безопасного доступа: `HOME-WORK-RU.md`.

После установки на рабочем столе появится ярлык **Packaging-Filling-Hub**. Повторный запуск установщика обновляет файлы программы и сохраняет локальный `.env` с настройками Google.

Для обновления используйте `UPDATE-MANAGER-WORK.cmd` на компьютере начальника или `UPDATE-SENIOR-MECHANIC-WORK.cmd` на компьютере старшего механика. Перед обновлением закройте программу, распакуйте новый ZIP в новую папку и запустите нужный файл. OAuth-настройки и пароль не переносятся между компьютерами и не удаляются при обновлении.

## Подключение корпоративного Google

Эта часть выполняется отдельно на каждом из трёх компьютеров после создания стандартного Google Cloud проекта, включения Apps Script API и получения Deployment ID. Использование корпоративного аккаунта дома должно быть разрешено правилами предприятия.

1. Скачайте JSON OAuth-клиента типа «Настольное приложение» только на настраиваемый компьютер.
2. Дважды нажмите `CONNECT-GOOGLE.cmd`, вставьте полный путь к файлу `client_secret_....json` и подтвердите корпоративный аккаунт в браузере.
3. Запустите `TEST-GOOGLE-CONNECTION.cmd`. Он проверит локальную программу и доступ Google.
4. Не включайте запись, пока в программе не проверены нужные журналы и справочники.
5. Только после отдельного решения запустите `ENABLE-GOOGLE-WRITES.cmd` и вручную введите `YES`. Затем перезапустите программу через ярлык.

OAuth client secret, refresh token и файл `.env` нельзя отправлять в чат или загружать на GitHub. После настройки удалите скачанный JSON с секретом.

## Установка как отдельного приложения

Откройте ярлык, затем в Microsoft Edge выберите **… → Приложения → Установить Packaging-Filling-Hub**. Адрес должен оставаться локальным: `http://127.0.0.1:4174`.

## Что входит в версию 0.9.1

- журнал контроля весов, персонал, смены, табель, спецификации продуктов и журнал очистки циклонов;
- журнал технического обслуживания: чтение, статистика, форма ввода и отдельная офлайн-очередь;
- Google-запись по умолчанию выключена. Она включается отдельно на каждом компьютере и только после контрольной проверки.

## Если интернет пропал

Не очищайте данные браузера и не удаляйте профиль Edge/Chrome, пока есть неотправленные записи. После появления интернета программа попытается отправить очередь автоматически.
