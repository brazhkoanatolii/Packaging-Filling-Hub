# Подключение Google Workspace

Рабочая интеграция пока намеренно выключена. Демонстрационные записи не могут попасть в производственную таблицу.

## Уже подготовлено в таблице

- защищённая функция Apps Script `writeScaleRecord`;
- блокировка параллельных изменений;
- версии записей и уникальные идентификаторы;
- защита от повторного запроса;
- технические даты и автор изменения;
- существующие формулы столбцов сохраняются.

## Что потребуется для включения

1. Корпоративный проект Google Cloud.
2. Внутренний OAuth-клиент организации.
3. Разрешённые Google Sheets, Drive и Apps Script API.
4. Закрытый серверный шлюз для хранения OAuth-токена. Токен не передаётся в PWA.
5. Папка на Общем диске для вложений.
6. Контролируемая тестовая запись с последующим аннулированием.

## Контракт записи

Серверный шлюз вызывает `writeScaleRecord` и передаёт:

- `requestId` — уникальный идентификатор запроса;
- `recordId` — постоянный идентификатор записи;
- `expectedVersion` — версия, которую видел пользователь;
- дату, весы, фактический вес, состояние, исполнителя и примечание;
- тип операции: создание, исправление или аннулирование.

API возвращает сохранённую запись, новую версию и вычисленные Google Sheets значения. При конфликте возвращается текущая версия для сравнения пользователем.
