# Архитектура приложения

## Поток данных

```text
Интерфейс → Сервисы → Репозиторий журналов → Поставщик данных
                                               ├─ IndexedDB: кэш и очередь
                                               └─ Google API: рабочий источник
```

Google Sheets является главным источником рабочих данных. IndexedDB хранит только локальный кэш, настройки текущего устройства и операции, которые ещё не удалось отправить.

## Правила

1. Интерфейс не обращается к Google или IndexedDB напрямую.
2. Любая запись сначала безопасно сохраняется на устройстве.
3. Каждая операция имеет уникальный `requestId` для защиты от повторной отправки.
4. Изменение содержит ожидаемую версию записи. При несовпадении показывается конфликт; данные не перезаписываются молча.
5. Удаление рабочих записей запрещено. Используется статус «Аннулировано» и обязательная причина.
6. Формулы Google Sheets не заменяются вычислениями приложения. После реального подключения окончательное значение результата возвращается из таблицы.
7. Секреты и токены не хранятся в репозитории и браузерном коде.

## Добавление журналов

Каждый журнал получает описание полей, разрешений и связи с источником. Общие механизмы авторизации, аудита, очереди, вложений и конфликтов остаются едиными.
