# Подключение журналов персонала к Google Sheets

Эта инструкция подключает отдельные рабочие журналы к программе. Google Sheets остаются главным источником данных; программа хранит на компьютере только кэш и очередь, когда интернета нет.

## Уже подготовленные журналы

- `Персонал` — список сотрудников, должность, смена и статус.
- `Табель 2027–2029` — три годовые вкладки и `Статистика`.
- `График отпусков 2027–2029` — три годовые вкладки и `Статистика`.
- `Журнал ремонта` и `Журнал ТО` — отдельные журналы, каждый со своей вкладкой `Статистика`.

Не переименовывайте рабочие вкладки и не меняйте скрытые служебные столбцы в новых трёх журналах: они нужны для синхронизации и аудита. Рабочие столбцы находятся слева и остаются обычными для просмотра и ручных исправлений.

## Один раз: Apps Script

1. Откройте существующий проект Apps Script, где уже находится `scale-journal-api-v2.gs`.
2. Создайте в нём файл `workforce-api.gs` и вставьте одноимённый файл из репозитория: `apps-script/workforce-api.gs`.
3. В настройках проекта задайте часовой пояс `Europe/Vilnius`.
4. В Google Cloud / OAuth добавьте области доступа `https://www.googleapis.com/auth/spreadsheets` и `https://www.googleapis.com/auth/script.scriptapp`.
5. Сохраните проект и создайте новую версию развёртывания API Executable. В настройках рабочего компьютера укажите его идентификатор развёртывания как `GOOGLE_SCRIPT_DEPLOYMENT_ID`.

Перед включением записи откройте в программе «Персонал» и нажмите «Обновить». Должен загрузиться список сотрудников из Google Sheets.

## Рабочие компьютеры

На компьютере начальника в `.env` назначьте:

```ini
WORKSTATION_ROLE=manager
WORKSTATION_ID=manager-pc
WORKSTATION_LABEL=Компьютер начальника
GOOGLE_WRITES_ENABLED=true
```

На компьютере старшего механика:

```ini
WORKSTATION_ROLE=senior
WORKSTATION_ID=senior-pc
WORKSTATION_LABEL=Компьютер старшего механика
GOOGLE_WRITES_ENABLED=true
```

Старший механик может изменять только табель; начальник — персонал, смены, табель и отпуска. Перед каждым изменением программа просит выбрать ФИО автора. При одновременном изменении одной записи Google не перезаписывается молча: будет предложено обновить данные и сохранить нужную версию.

## Проверка перед вводом рабочих данных

1. Откройте программу, войдите и нажмите «Обновить».
2. Убедитесь, что в «Персонале» видны сотрудники из отдельного журнала.
3. На копии или в тестовой строке измените одну ячейку табеля; выберите автора, сохраните, затем обновите страницу Google Sheets.
4. Проверьте, что в строке появились дата изменения и ФИО автора.
5. Только после этого начинайте заполнять рабочие данные.

Если сеть пропадёт, изменение останется на том же компьютере и отправится автоматически после восстановления сети.
