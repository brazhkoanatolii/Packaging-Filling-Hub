# Журнал технического обслуживания

Источник: `1SRirurDOMqyGEXj2oo_V81CQ5jKnnvg9nN8G21QAFAY` («Журнал ТО»).
Листы определяются по точному шаблону `ТО NN`; на 21.09.2026 существуют ТО 01–ТО 16.
Строка 4: «Дата», «Имя, Фамилия», «Примечания». Данные начинаются со строки 5.
Исполнитель должен быть действующим сотрудником корпоративного персонала и присутствовать в `Справочники!A2:A1000` этого журнала.

## Поток данных

UI → MaintenanceService → MaintenanceRepository → MaintenanceGatewayProvider → локальный шлюз → Apps Script.
Локальный кэш и очередь изолированы в IndexedDB `packaging-filling-hub-maintenance`.
Репозиторий использует общую транзакционную очередь журнала очисток. Повтор после потери ответа сохраняет requestId; Apps Script под блокировкой проверяет квитанции во всех листах ТО.

`GET /api/maintenance-records` вызывает `listMaintenanceRecords`: records, machines, performers.
`POST /api/maintenance-records` вызывает `createMaintenanceRecord`: requestId, recordId, machine, date, performer, note. Роль и устройство задаются сервером.

Запись требует одновременно `GOOGLE_WRITES_ENABLED=true` на компьютере и свойства скрипта `PFH_TO_WRITES_ENABLED=true`. Оба разрешения включаются только после отдельного подтверждения пользователя. Тестовые записи в рабочую таблицу не создаются автоматически.
Добавление атомарно записывает A:C и квитанцию в примечании A; формат и проверка данных копируются с первой строки данных. Существующие строки не исправляются и не удаляются. Дата фиксируется при добавлении; API редактирования отсутствует.

## Статистика

Вкладка `Статистика`, sheetId `2000001000`: итоги B5:B7, станки A10:D26, месяцы A30:B42, годы A46:B51, сотрудники A55:C. Диаграммы справа, начиная с F10, F30, F46, F55.
Год выбирается в B3 (2000–2100). Формулы станков и месяцев используют существующие 16 листов; при добавлении нового станка эти формулы нужно расширить. Итоги по годам и сотрудникам пересчитываются из исходных строк, включая исторических сотрудников. Программа определяет набор листов автоматически.
Контрольная сумма исходных данных: 221 запись — 75 за 2024 год, 96 за 2025 год, 50 за 2026 год. Статистика программы исключает неподтверждённую очередь.
