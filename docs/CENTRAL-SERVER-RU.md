# Центральный сервер участка

## Назначение

Центральный сервер устанавливается на постоянно включённом компьютере старшего
механика. Только он хранит локальное подключение к Google и выполняет утренние
передачи итогов. Остальные компьютеры открывают программу через него и не
получают OAuth-файлы, токены Google или локальный `.env`.

```text
Компьютер начальника ─┐
                       ├── Центральный сервер на компьютере старшего механика ── Google Sheets
Компьютер администрации┘
```

## Права

Права определяются учётной записью на центральном сервере, а не компьютером:

| Учётная запись | Права |
| --- | --- |
| Администрация | Полный доступ: журналы, персонал, настройки, спецификации, пароли. |
| Старший механик | Разрешённые журналы и работа со сменой. |
| Администрация в будущем | Только просмотр после отдельного добавления роли. |

Пароли сохраняются на сервере только в виде хэшей. Они не находятся в браузере
и не передаются на компьютер начальника.

## Первичная установка

1. На компьютере старшего механика распакуйте пакет программы.
2. Обычным двойным щелчком запустите `INSTALL-CENTRAL-SERVER.cmd`. Не запускайте этот файл от имени администратора: программа должна установиться в профиль старшего механика.
3. Задайте разные пароли начальника участка и старшего механика; минимум шесть символов.
4. Один раз выполните `CONNECT-GOOGLE.cmd` и контроль `TEST-GOOGLE-CONNECTION.cmd` на этом же компьютере.
5. Убедитесь, что программа открывается локально по `http://127.0.0.1:4174`.
6. Узнайте имя компьютера или закрепите для него постоянный IP-адрес.
7. Дважды нажмите `ENABLE-CENTRAL-FIREWALL.cmd` и подтвердите запрос Windows на права администратора. Он создаст правило Windows Firewall только для частного профиля и локальной сети. Если администраторских прав нет, передайте этот один шаг IT.

## Подключение компьютера начальника

1. На компьютере начальника распакуйте тот же пакет.
2. Запустите `INSTALL-MANAGER-NETWORK-CLIENT.cmd`.
3. Введите адрес центрального сервера, например `http://PACKAGING-SENIOR:4174`.
4. Откройте созданный ярлык и войдите как «Администрация».

На компьютере начальника не требуется Node.js, OAuth или отдельное подключение
к Google. Если центральный сервер выключен, программа показывает отсутствие
связи; новые производственные факты не подтверждаются до восстановления
центрального сервера.

## Ограничения безопасности

- Не открывать порт программы в интернет.
- Не копировать `.env` или файл `.runtime/central-accounts.json` на другие компьютеры.
- Для доступа из дома в будущем использовать только согласованный VPN.
- Перед реальным подключением проверить вход начальника, вход старшего
  механика, запрет действий старшего механика в спецификациях и запись одной
  контрольной строки в рабочий журнал.
