# Очистка циклонов

Раздел программы записывает дату очистки и исполнителя в существующий журнал
`1jEpmScclwvmIhhiHnBi0EE5kRBGNLtfmP4zepkAMQDU`, лист «Очистка циклонов», A:B с четвёртой строки.
Исходные строки, справочник «Сотрудники» и вкладка «Статистика» не изменяются.
Добавление строк автоматически учитывается формулами статистики в Google Sheets.

## Что реализовано

- Ввод в программе для начальника и старшего механика, обязательный выбор исполнителя из персонала.
- Дата по умолчанию — сегодня в Europe/Vilnius; допускается фактическая прошедшая дата.
- Запись и операция отправки сохраняются одной транзакцией в отдельной IndexedDB `packaging-filling-hub-cyclones`.
- Обновление и повторная отправка при восстановлении сети, каждую минуту и вручную.
- Неподтверждённые записи остаются в очереди с текстом ошибки, отдельно от подтверждённой статистики.
- Статистика за год: данные слева, график справа. Google — главный источник, локальные записи — кэш и очередь.
- Этот этап поддерживает чтение и добавление очисток. Исправление существующих строк через интерфейс ещё не реализовано.

## Подключение — только после подтверждения начальника

На текущем рабочем компьютере OAuth отсутствует. До настройки программа честно показывает отсутствие связи, не заменяет журнал демонстрационными записями и не объявляет локальные записи отправленными.

1. В существующий проект Apps Script API executable добавить `apps-script/cyclone-journal-api.gs`. Он использует уже существующую `listPersonnel` из `scale-journal-api-v2.gs`.
2. Включить расширенный сервис Google Sheets API (`Sheets`, v4) и Sheets API в связанном Google Cloud проекте. Нужен атомарный `batchUpdate`, чтобы потеря ответа не создавала повторную строку.
3. Для доступа к нескольким существующим таблицам нужен OAuth scope `https://www.googleapis.com/auth/spreadsheets` — чтение и изменение Google-таблиц, доступных корпоративной учётной записи. `spreadsheets.currentonly` недостаточен для `openById` других книг. Текущий OAuth-помощник запрашивает `spreadsheets` и `script.scriptapp`; запускать его только после согласования этих разрешений. Области OAuth-клиента должны соответствовать развёрнутому проекту Apps Script.
4. Опубликовать новую версию API executable. Настроить локальные OAuth-параметры и Deployment ID без передачи секретов в чат или Git.
5. При `GOOGLE_WRITES_ENABLED=false` проверить только `GET /api/cyclone-records` и сравнить даты, имена, статистику с журналом.
6. Только по отдельному подтверждению включить **оба** переключателя: локальный `GOOGLE_WRITES_ENABLED=true` и Script Property `PFH_CYCLONE_WRITES_ENABLED=true`. Перед включением проверить накопившуюся очередь, включая очереди других разделов: общий флаг разрешает их автоматическую отправку.
7. Согласовать одну реальную или контрольную запись и её повторную отправку. Скрипт хранит идентификатор запроса в примечании новой ячейки даты, атомарно с данными A:B. Старые примечания и записи не трогает.

Не очищать данные браузера, пока есть записи в очереди. Все локальные тесты используют заглушки и не обращаются к рабочим таблицам.
